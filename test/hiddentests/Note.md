# Hidden tests 的生成与验证说明

这里面的各个测试点和它对应的答案是LLM按模块分批生成的.

对于每个模块,每个in文件测试了该模块里面某些特定的功能,由LLM基于对该功能的理解建立了输入序列

ans文件比较有意思,由于我们在Advanced部分中对于Vim的某些行为进行了简化,我们没法直接用vim生成ans文件.也就是说我们的MiniVim预期输出和Vim可能有轻微不同.而我们手上也没有一份确保bug-free的包含README中所有advanced部分实现的MiniVim.于是我们让LLM仔细阅读了模块的README要求,并且根据这些要求直接建立了MiniVim模型,然后将in文件里面的对应输入序列给放进MiniVim模型中进行计算,输出了理论上的快照.为了建模正确,我们接下来让真实Vim在vtemu上跑了指令序列,并且将两者的输出进行了比对.在比对中确保了快照的不同之处都在我们的README行为规范预期之内(中途发现了README的bug已对README和ans进行了修订)

这样我们就得到了ans文件.也就是说原则上只要同学的实现和README中当前标准相同,他的输出就应该和ans相同.
但我们依然不保证ans均是100%正确的,如果你发现了什么问题,随时联系我们.
